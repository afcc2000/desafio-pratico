Precisamos de um tela para abertura de chamado usando os requisitos definidos no email.md.

1 - Analisar e levantar os requisitos do arquivo e-mails.md
2 - Usar o arquivo formulario-exportado.json como base para coleta dos dados para a abertura no GLPI.
3 - O arquivo resposta-api-exemplo.json devera ser usado como base o retorno de abertura do chamado com status, ticket e etc, sem mais e nem menos.
4 - O arquivo usuario-logado.json é pra usar também como base para parte de login.
